Project Colophon & Technical Compliance

This website was developed as part of an academic web development assignment at Astana IT University.

Standards & Principles

  • Strict HTML5 Semantics: No CSS styling or JavaScript scripts were applied to meet standard accessibility guidelines.
  • Structural Validation: Utilized elements such as <header>, <nav>, <main>, <section>, <article>, and <footer>.
  • Accessibility (a11y): All images use accurate alt text descriptions, forms utilize explicit <label for=""> connections, and tables feature <caption> and scope attributes.
