How This Site Was Made

Website written with HTML, no CSS and no JavaScript. Built clean, semantic structure first, styling reserved for later.

Each team member wrote their code in IntelliJ IDEA, using its built-in live preview to check the page in the browser while editing. The project is shared through a single GitHub repository.

All photos used across the site were produced from the actual gyms, not generated. Every page was checked with the W3C Markup Validator before each commit.
